# Network Engineering Portfolio

A practical portfolio documenting my development in enterprise networking, routing, network security, ISP/WAN technologies, and network operations.

## Purpose

This repository contains hands-on networking labs, designs, configurations, verification results, troubleshooting notes, and technical documentation developed as part of a structured network engineering learning programme.

## Project Standards

Each completed project will aim to include:
- Requirements and network design
- Topology diagram and IP addressing plan
- Device configurations with credentials and sensitive information removed
- Implementation notes
- Verification commands and test results
- Troubleshooting records and lessons learned
- A professional technical report

**Lab disclaimer:** Packet Tracer projects are simulations for learning and portfolio demonstration. They are not representations of live production deployments.

## Portfolio Roadmap

| Area | Focus |
|---|---|
| Enterprise LAN Engineering | VLANs, trunking, inter-VLAN routing, DHCP, STP, ACLs, SSH and switch security |
| Enterprise Routing | Static and dynamic routing, OSPF, BGP fundamentals and multi-site connectivity |
| Network Services and Security | NAT/PAT, DNS, access control, VPN concepts and hardening |
| ISP and WAN Engineering | WAN links, provider/customer routing, BGP, MPLS fundamentals and Ethernet services |
| NOC and Network Operations | Monitoring, SNMP, syslog, fault isolation and incident handling |
| Advanced Networking | Redundancy, high availability, QoS, IPv6 and advanced switching |
| Capstone Projects | Integrated enterprise and service-provider scenarios |
